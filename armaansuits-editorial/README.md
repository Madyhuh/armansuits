# ArmaanSuits — Editorial Bridal Homepage Demo

A responsive, one-page informational website concept for ArmaanSuits near Marine Drive, Mumbai. The visual direction is a South Asian bridal fashion editorial: deep wine, warm ivory, antique gold, cinematic imagery, large refined typography, asymmetric collection cards, and a horizontal Reel rail. It is a concept demo, not an official store website.

## Preview

Open `index.html` in a browser. An internet connection is needed for the Google Fonts; all image assets are included locally.

## Add the real Instagram Reel links

In `index.html`, search for `PASTE_INSTAGRAM_REEL_LINK_1` and replace each of the five placeholder Reel IDs/URLs with the full public ArmaanSuits Reel URL. For example, if a real link is `https://www.instagram.com/reel/ABC123/`, replace the placeholder URL with that exact URL. The image cards already scroll horizontally and open the Reel in a new tab.

Replace the Instagram profile link near the end of the Reel section (`id="instagram-profile"`) with the store's actual profile URL.

## Before showing/publishing to the client

- The included bridal images are concept imagery generated for this demo, not actual ArmaanSuits products or customers. Replace them with approved store photography before presenting the site as a live catalogue.
- Confirm the exact address, opening hours, contact number, appointment process and official Instagram URL with the store. The map button currently searches for ArmaanSuits near Marine Drive and is only a starting point.
- Edit the wording in `index.html` to match the store's real services and brand voice.
- The collection cards currently scroll to the visit/appointment section; no online shopping or pricing is implied.
